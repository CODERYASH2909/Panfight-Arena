This folder is intentionally empty.

All PenFight Arena visuals (pens, bench, arenas, particles, effects) are
drawn procedurally on <canvas> in static/js/engine.js, and all UI iconography
uses inline emoji/CSS rather than image assets. This keeps the project a
fully self-contained, dependency-free download.

Drop custom artwork here (pen sprites, arena backgrounds, etc.) if you want
to extend the canvas renderer to use bitmap assets instead.
